# 실버테라피 구조 확인 확장 프로그램 (진단 전용)

첫 검증 대상: 스마트스토어 품번 `R221057427`, 사이즈 `11`. 검색 키는 `57427`, 분류 코드는 `R`입니다.

실제 검색·상세 데이터의 확인 결과와 미검증 항목은 [분석 기록](../../docs/SILVERTHERAPY-RESEARCH.md)에 정리합니다. 수집기 업데이트 후에는 `chrome://extensions`에서 이 확장 프로그램의 새로고침 버튼을 누르고 팝업을 다시 여세요.

## 설치 (Windows / macOS Chrome)

1. 프로젝트 루트에서 `pnpm inspect:supplier`를 실행합니다. 루프백 `127.0.0.1:43187`만 사용하는 로컬 진단 수신기가 실행됩니다.
2. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `apps/supplier-inspector` 폴더를 선택합니다.
4. 실버테라피에 직접 로그인한 Chrome에서 확장 프로그램을 실행합니다.
5. **끝 5자리 검색 탭 열기**를 누릅니다. 새 검색 탭에서 확장 프로그램을 다시 열고 **현재 페이지 분석** → 미리보기 확인 → **이 PC의 루메뜨 진단 도구로 보내기**를 누릅니다.
6. 검색 결과 중 `R`로 시작하고 `57427`로 끝나는 상품의 상세를 직접 열고, 같은 방식으로 분석·전송합니다. 여러 개라면 임의 선택하지 말고 검색 결과까지만 전송합니다.
7. 11호 옵션이 화면에 있으면 선택하고 분석·전송합니다. 주문/장바구니 버튼은 누르지 않습니다.
8. 같은 상세를 새로고침하고 한 번 더 전송하면 옵션 식별자 후보의 재로딩 안정성을 비교할 수 있습니다. 장기간 안정성이 입증되는 것은 아닙니다.

Windows 폴더: `D:\lumette-admin\apps\supplier-inspector`

macOS 폴더: clone한 저장소의 `apps/supplier-inspector`

진단 파일은 저장소의 `.diagnostics/silvertherapy`에 저장됩니다. 이 폴더와 단기 연결용 `local-settings.js`는 Git에서 제외합니다. 수신기는 30분 또는 최대 20회까지만 사용합니다. 재시작하면 연결키가 바뀌므로 확장 팝업을 닫고 다시 엽니다. 오류 발생 시 회사 정책에 의해 확장 설치가 제한되어 있는지도 확인하세요. 보안 정책을 우회하지 않습니다.

## 수집 범위와 검증 상태

- 사용자가 분석 버튼을 누른 현재 실버테라피 탭의 허용된 상품 필드 후보만 읽습니다.
- 쿠키 API, 웹 요청 헤더, 세션 저장소, 페이지 전체 HTML, 인라인 스크립트는 읽지 않습니다.
- URL은 상품 코드/5자리 검색어만 남기고 세션 등 다른 쿼리 파라미터는 버립니다.
- 상품 필드·선택지·옵션 행 텍스트를 미리보기로 확인한 뒤에만 이 PC로 전송합니다. 외부 서버나 Neon DB로 보내지 않습니다.
- 기본 가격, 옵션 ID, 옵션별 가격의 의미는 아직 미검증입니다. 가격 누락을 기본 가격으로 채우지 않습니다.
- 검색 0건도 `UNVERIFIED`로 기록합니다. 로그인 성공/정상 검색 결과 표식이 검증되기 전에는 품절을 판정하지 않습니다.
- 필드 허용 목록 밖의 가격 구조는 수집되지 않을 수 있습니다. 실제 결과를 확인하며 필요한 상품 필드만 추가할 예정입니다.
- 이 프로그램은 전체 상품 수집기나 운영 동기화 확장 프로그램이 아닙니다. 관리자 인증·스마트스토어 실제 목록 연결은 다음 단계입니다.

## 검증

`pnpm test:inspector`는 품번 추출, URL 세션 제거, 인증정보·HTML 거부, 합성 DOM의 상품 필드 선별을 검사합니다. 합성 테스트는 실제 실버테라피 HTML 검증을 대신하지 않습니다.
